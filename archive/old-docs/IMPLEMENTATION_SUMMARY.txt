HOW TO USE
═══════════════════════════════════════════════════════════════════════════════════

OLD WAY (Before Fix):
  1. Define and prepare motors
  2. Start motors (run)
  3. Stop motors
  4. Change parameters  
  5. Click Start → ❌ PARAMETERS DON'T UPDATE
  6. Must: Turn Off → Rehome → Redefine → Start (very slow!)

NEW WAY (After Fix):
  1. Define and prepare motors
  2. Start motors (run)
  3. Stop motors
  4. Change parameters (e.g., Speed 1: 500 → 700)
  5. Click Start → ✅ "Parameters changed - updating motors..."
  6. Motors run with new parameters in ~1 second!
